# Changes

## 1.0.0rc1

- Added streaming downloads, confined static roots, HEAD responses and binary bodies.
- Added source file/line diagnostics and try/catch/raise with Spanish learning aliases.
- Added `ron new`, `run`, `check`, `fmt`, `test` and source/frozen/pip entry points.
- Added navigation, links, images and CSS/JavaScript asset helpers.
- Added salted scrypt passwords, server-side sessions, rotation, expiry and CSRF.
- Added atomic SQLite migrations and an optional PostgreSQL adapter.
- Added bounded HTTP workers, a basic request rate limit and method/status logs.
- Added a Windows executable/installer build, portable package and VS Code extension.
- Added container/proxy configuration, expanded CI and release validation checklist.
- Standardized examples, filenames, messages and documentation on English; preserved
  optional Spanish syntax aliases.

## 0.5 / 0.4

- Bilingual syntax, modules, loop control, expressions cache and CLI version.
- Route parameters, response headers/status, forms and SQLite task example.
- Statistics, CSV, matrices, linear regression, JSON HTTP and environment helpers.

## 0.3

- Initial HTML helpers, API server, collections and a browser game example.

## 0.2

- Functions, parameters, returns, concatenation and compatibility tests.
